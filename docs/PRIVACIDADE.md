# Privacidade e auditoria de rede

O código próprio não envia texto, documentos ou medições, não usa API remota de IA e não tem analytics. O desktop bloqueia `socket.connect`/`socket.getaddrinfo` no processo de inferência. Somente o instalador usa HTTP para pesos, mediante consentimento.

No Android, a execução real revelou o SDK ML Kit registrando eventos de desempenho `FIREBASE_ML_SDK` para o transporte CCT/Firelog. Isso é comportamento do SDK, não inferência remota. Para impedir upload desse transporte, o manifest remove `TransportBackendDiscovery` e desativa a opção global Firebase. A reexecução real registrou `Transport backend 'cct' is not registered`, com tradução funcionando. O merge final deve permanecer sem `CctBackendFactory` a cada upgrade. A remoção de descoberta é uma mitigação específica da implementação atual, não uma API oficial de opt-out do ML Kit.

Fontes oficiais: [divulgação de dados ML Kit](https://developers.google.com/ml-kit/android-data-disclosure); [descoberta de backend](https://github.com/firebase/firebase-android-sdk/blob/master/transport/transport-runtime/src/main/java/com/google/android/datatransport/runtime/backends/MetadataBackendRegistry.java); [uploader descarta backend ausente](https://github.com/firebase/firebase-android-sdk/blob/master/transport/transport-runtime/src/main/java/com/google/android/datatransport/runtime/scheduling/jobscheduling/Uploader.java). Downloads de modelos/configuração Google continuam sendo contatos externos consentidos, distintos de enviar texto do PDF. Não alegar auditoria completa de todos os componentes fechados do SDK nem garantia equivalente no iOS não testado.

O script `scripts/test_android_offline.py` baixa modelos primeiro e observa a mensagem de prontidão do teste. Antes da inferência, ativa modo avião e desliga Wi-Fi/dados apenas no AVD `emulator-5554`. O código Android confirma ausência de rede ativa por `ConnectivityManager`, só então a avaliação segue sem cache. O script restaura o estado anterior em `finally` e registra `reports/network-audit.json`. Isso demonstra operação sem rede; não prova inexistência de toda tentativa de conexão do SDK. A ausência de upload CCT tem evidência separada no manifest e nos logs. A primeira instrumentação, que usava callback de screenshot processado somente ao fim, foi descartada como prova de offline; números dessa execução anterior permanecem identificados no arquivo `benchmark-android-variable-length.json`.

**Build debug:** o ML Kit nativo imprime frases sintéticas traduzidas e matrizes no logcat. Não há texto privado nos relatórios fornecidos (somente fixtures públicas), mas não usar build debug com documentos sensíveis enquanto esse logging do SDK não for auditado/silenciado numa build release. A aplicação não copia esses logs para telemetria. Esta é uma limitação real descoberta na instrumentação.

Preferências do comparador são locais, com proveniência `user-preference-not-gold` e `labelConsent=false`. Não são usadas como gold nem enviadas a servidor. Banco e bases internas dos PDFs ficam em armazenamento privado do aplicativo; não há criptografia adicional ou backup/sincronização implementados. No Windows, Salvar grava marcações e traduções no PDF original escolhido pelo usuário; o banco também guarda seu caminho e hash localmente. A política de backup Android foi desativada no manifest para evitar cópia automática de dados pelo aplicativo.
